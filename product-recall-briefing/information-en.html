CORE CAPABILITIES

Built around the work a recall briefing needs to do.

Source coverage, focused retrieval, clear classification, and details you can check. No invented certainty where the source has none.

01

Four sources, one structure

Bring CPSC consumer-product recalls and openFDA drug, food, and device records into consistent fields, with source status visible.

02

Focused queries

Set category, date range, and result limit. In the tablets example, keyword filtering targets openFDA drug records—not CPSC.

03

Risk classes with context

Retain FDA Class I / II / III and count classes among displayed records. CPSC entries remain unclassified under the FDA scheme.

04

Details you can trace

See the reason, firm, date, and recall number. CPSC retains its notice link; openFDA records use recall numbers rather than invented per-record URLs.

HOW IT WORKS

A straightforward path from question to record.

Define the scope, read the briefing, and return to official records when a model, lot, or action matters.

01

Set the scope

Choose all categories or one, then set the date window and number of records to display. Add a keyword where supported. Dates default to the past 30 days.

02

Query public sources

The selected CPSC or openFDA endpoints are queried. The status of each queried source remains visible.

03

Normalize and organize

Different response formats become a common record structure. Multi-category results rotate across sources instead of letting one fill the page.

04

Review and verify

Read the list and category or FDA-class counts, then use the CPSC notice or FDA recall number to confirm details.

SOURCE-AWARE BY DESIGN

Trust starts with clear boundaries.

The briefing carries public-source data forward while preserving what a source does—and does not—provide.

CPSC ↗FDA ↗
✓

Visible source status

Every query identifies which selected sources were available. All four responded in the cross-category example shown here.

✓

No inferred class or link

CPSC records are not assigned FDA classes. Where openFDA has no per-record notice URL, the recall number remains the reference.

✓

Official records remain primary

A briefing helps locate and understand recalls; it is not exhaustive or a substitute for CPSC or FDA notices, or medical, legal, or safety advice.
