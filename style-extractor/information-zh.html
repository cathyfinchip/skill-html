02 / 变化

从“这种感觉”，到具体要求。

文章参考

Before

After

得到句长、人称、节奏等特征，以及对应的原文证据和风格提示词。

视觉参考

Before

After

03 / 使用场景

参考很多，开始创作时还是说不清。

写品牌文案时，你希望保留参考文章的语气，却不想照搬主题。准备海报时，你喜欢参考图的配色和布局，却不知道如何把要求讲给设计师或 AI。

把参考中的特征整理下来，写作者、内容运营和视觉创作者就能围绕同一份要求讨论、调整和交接。

04 / 从观察到要求

把感觉写成可以讨论的要求。

“句子短一些”“用第二人称”“保留低饱和配色”，比“再有感觉一点”更容易理解，也更方便调整。先决定哪些特征要保留，再交给后续创作环节。

05 / 使用方式

提供参考，提取特征，带走提示词。

01

提供参考

提供中文或英文正文，或 PNG、JPEG、GIF 图片。图片的构图、光线等观察由实际看图的 AI 补充。

02

查看分析

文章提取结构、词汇和部分语气特征；图片读取尺寸、比例，支持的 PNG 还能提取主色、亮度和饱和度。

03

继续创作

带走风格说明和提示词，添加新主题、目标受众与任务要求，再交给创作工具。此 Skill 本身不生成文章或图片。

07 / 核心优势

有依据，也方便继续使用。

描述有依据

文章附有统计和原文短句，图片区分文件数据与 AI 观察，方便核对来源。

输出可以复用

两种模式都输出风格说明和提示词，方便整理进创作简报或团队参考库。

缺失信息明确列出

未提供的视觉观察会单独列出；不能提取色板时会说明限制。

提取脚本本地运行

Python 标准库即可运行，无需 API Key 或额外依赖。看图 AI 的处理方式取决于所用工具。

能力边界
文章分析采用规则与统计，需结合原文判断。可读性为内部参考指标；中文“生僻字”由有限常用字表判定，不作为内容质量评分。色板提取限支持的 PNG；JPEG、GIF 读取尺寸等文件头信息。
