03 / THE CREATIVE BRIEF

Make creative references easier to use.

A reference can communicate a direction without explaining the decisions behind it.

For a writer, the useful detail may be short paragraphs or direct address. For a designer, it may be a limited palette or a particular lighting treatment. Document those choices so your team can review, adjust, and share them.

04 / MAKE IT ACTIONABLE

Describe the decisions behind the style.

“Use short sentences and address the reader directly” gives collaborators something concrete to work with. Identify the relevant characteristics, choose what to retain, and adapt the brief to your project.

05 / HOW IT WORKS

A reference in. A working brief out.

01

Add your reference

Provide Chinese or English text, or a PNG, JPEG, or GIF image. A vision-capable AI supplies observations about visible image characteristics.

02

Review the analysis

Review writing metrics and selected tone indicators. For images, inspect dimensions and proportions, plus color data for supported PNG files.

03

Reuse the brief

Take the description and prompt into your next task. Add the subject, audience, and project requirements. Content generation happens in your chosen creative tool.

07 / BUILT FOR REVIEW

Built for review and reuse.

Traceable descriptions

Writing outputs include measurements and source excerpts. Image outputs separate file properties from AI-supplied observations.

Consistent outputs

Both modes return a style description and prompt for use in creative briefs and reference libraries.

Explicit gaps

Unprovided visual observations are listed separately. The output notes when palette extraction is unavailable.

Local processing

The extraction script uses the Python standard library and needs no API key. Any AI used to inspect images operates separately under its own processing settings.

Scope and limitations
Writing analysis uses rules and statistics and supports editorial judgment. Readability is an internal proxy, not a quality score; the Chinese rare-character measure uses a limited common-character list. Palette extraction is limited to supported PNG files. JPEG and GIF parsing provides header information such as dimensions.
