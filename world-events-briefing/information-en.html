CORE CAPABILITIES

Core capabilities

Organize global current events by date, country term, or keyword while retaining the source name and original link.

01 / DAILY

Previous-day briefings

Generates dated, numbered current-event results for the previous UTC day, with original sources attached.

02 / COUNTRY

Country-term filtering

Applies a case-insensitive substring match to Wikipedia event text and returns potentially relevant entries.

03 / KEYWORD

Keyword briefings

Matches keywords across titles, descriptions, topics, and categories. Daily runs can be combined into a month-wide set.

04 / LIMIT

Controlled item counts

Enforces the maximum requested in the prompt.

05 / SOURCES

Source traceability

Retains a named source and original link for every displayed result, supporting direct review.

06 / DEGRADE

Single-source degradation

When GDELT is rate-limited or times out, the run can still complete with Wikipedia Current Events results.

HOW IT WORKS

From prompt to sourced result

The native interface processes one date per call. The past-month set was produced through daily runs, then merged and deduplicated by URL.

STEP 01

Define the request

Choose a date or yesterday, then add a country term, keyword, and maximum item count.

STEP 02

Fetch sources

Read Wikipedia Current Events and attempt the GDELT DOC 2.0 query.

STEP 03

Apply filters

Match country terms or keywords against the event text.

STEP 04

Assemble results

Normalize entries, deduplicate URLs, and enforce the requested item cap.

STEP 05

Return the briefing

Provide dates, categories, topics, source names, and original links.

USE CASES

Three practical working patterns

Cover daily briefings, country-term discovery, and month-wide keyword summaries. Month-wide searches are assembled through daily calls and merging.

USE 01

Daily current-event briefings

Create a controlled set of global events for the previous UTC day, with a source retained for every item.

USE 02

Country-term discovery

Filter a day’s event text with terms such as America or Iran to identify potentially relevant entries.

USE 03

Month-wide keyword briefings

Search election day by day, merge and deduplicate the results, then return up to ten of the most recent matches.

RELIABILITY

Trust through transparent boundaries

The Skill uses public endpoints without an API key, preserves source links, and clearly surfaces external-source status.

01

Public endpoints

No external API credentials are required.

02

Sources retained

Named sources and original links remain visible for direct review.

03

Independent failure

Wikipedia results can still return when GDELT produces HTTP 429 or times out.

Known limits

  • Country filtering is a substring match. America can match both American and South America.
  • Keyword matching covers titles, descriptions, topics, and categories, so election may include indirectly related entries.
  • A past-month range requires daily runs, merging, and URL deduplication.
