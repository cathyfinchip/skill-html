CORE CAPABILITIES

核心能力

按日期、国家相关词或关键词整理全球时事，并在输出中保留来源名称与原始链接。

01 / DAILY

昨日全球简报

按 UTC 昨日生成带日期、编号和来源的全球时事结果。

02 / COUNTRY

国家相关词筛选

对 Wikipedia 事件文本做不区分大小写的子串匹配，返回相关条目。

03 / KEYWORD

关键词简报

在标题、描述、主题和分类中匹配关键词，可通过逐日运行组成月度集合。

04 / LIMIT

输出数量上限

按 Prompt 中的数量限制控制最终结果。

05 / SOURCES

来源可追溯

每条结果保留来源名称与原始链接，用户可以回到新闻来源复核。

06 / DEGRADE

单源失败降级

GDELT 限流或超时时，整体运行仍可返回 Wikipedia Current Events 结果。

HOW IT WORKS

从 Prompt 到带来源的结果

核心接口一次处理一个日期。近一个月的结果由按日调用、合并与 URL 去重完成。

STEP 01

定义请求

指定日期或昨日，再加国家相关词、关键词和最大条数。

STEP 02

抓取来源

读取 Wikipedia Current Events，并尝试查询 GDELT DOC 2.0。

STEP 03

筛选内容

对事件文本应用国家相关词或关键词匹配。

STEP 04

合并整理

规范化条目，按 URL 去重，并应用输出数量上限。

STEP 05

输出简报

输出日期、分类、主题、来源名称与原始链接。

USE CASES

三种典型工作模式

覆盖每日简报、国家相关词检索和月度关键词汇总。月度关键词检索通过按日调用后合并实现。

USE 01

每日时事摘要

为前一个 UTC 日生成有限条数的全球简报，并保留每条来源。

USE 02

国家相关词检索

使用 America 或 Iran 等词筛选当日事件，快速定位可能相关条目。

USE 03

月度关键词简报

逐日检索 election，合并并去重，在最近结果中输出最多 10 条。

RELIABILITY

可用性来自透明的边界

Skill 使用公开端点，无需 API Key；每条结果保留来源链接，并清晰呈现外部数据源状态。

01

公开端点

无需配置外部 API 凭证。

02

来源保留

结果中显示来源名称与原始链接，支持后续复核。

03

独立失败

GDELT 出现 HTTP 429 或超时时，Wikipedia 结果仍可返回。

已知限制

  • 国家筛选是文本子串匹配；America 可同时命中 American 和 South America。
  • 关键词会匹配标题、描述、主题和分类；election 可包含间接相关条目。
  • 近一个月范围需要按日运行、合并与 URL 去重。
